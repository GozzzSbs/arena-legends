# ARENA LEGENDS

ARENA LEGENDS est un jeu de combat en arène 2D jouable directement dans un navigateur.

## Fonctionnalités

- 8 personnages originaux.
- Lobby avec sélection des combattants.
- Battle Royale solo.
- 7 adversaires contrôlés par l'intelligence artificielle.
- Zone dangereuse qui rétrécit.
- Système de points de vie.
- Attaques et esquives.
- Éliminations.
- Système de niveaux.
- Interface responsive.

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas 2D

## Installation

Télécharge les fichiers et ouvre index.html dans ton navigateur.

## Commandes

- ZQSD : déplacement.
- WASD : déplacement.
- ESPACE : attaque.
- MAJ : esquive.

## Publication

Le jeu peut être hébergé gratuitement avec GitHub Pages.

1. Créer un dépôt GitHub.
2. Ajouter les fichiers à la racine.
3. Ouvrir Settings.
4. Aller dans Pages.
5. Sélectionner Deploy from a branch.
6. Sélectionner main et /(root).
7. Enregistrer.

Le jeu sera accessible depuis ton adresse GitHub Pages.
